# CICRS 鸿蒙端功能差异清单

此清单以原 CICRS `docs/PRD.md` 与三端产品结构为准。HAP 能构建只说明 ArkTS 编译打包成功，不等于功能已验收。

## 产品边界

| 产品 | 鸿蒙工程/现状 |
|---|---|
| 学生端 | `CICRS-Student-Harmony`，独立包名 `com.cicrs.greenhub.student` |
| 回收员端 | `CICRS-Recycler-Harmony`，独立包名 `com.cicrs.greenhub.recycler` |
| 管理后台 | 原项目 `admin-web`（Vue Web），当前没有改造成鸿蒙原生管理端 |

学生和回收员 HAP 目前各自使用本地 Preferences 演示仓储。由于尚未连 CICRS CloudBase / PostgreSQL 部署，两端之间不共享演示数据；本机完成预约不代表另一应用能看到该预约。

## 按 PRD 模块核对

| PRD 模块 | 当前实现 | 尚未完成 / 验收边界 |
|---|---|---|
| M-01 发布闲置 | 本机发布、因子品类、成色、流转方式、数量、可选估重、鸿蒙照片选择、状态轨迹 | 尚无登录鉴权、图片上传/压缩与大小/格式校验、敏感词检查、编辑/草稿恢复；数据仅本机 |
| M-02 浏览检索 | 本机在库列表、名称/品类筛选、物品详情、预约入口 | 缺成色/驿站/综合排序筛选、详情实时库存和跨用户共享 |
| M-03 预约投递/领取 | 本机选驿站、半小时段、显示二维码及核销码、取消与过期状态处理 | 时段只提供有限的本机候选；缺未来 7 天完整时段、容量实时数据、并发原子占位、云端预约单 |
| M-04 碳账户 | 本机积分、减排估算、树木换算、完成次数和积分明细 | 缺近 6 月趋势、真实余额与排名百分位、跨用户历史数据 |
| M-05 消息与我的 | 个人资料入口、我的发布/预约、状态动态、规则说明 | 缺真实登录/学号手机号绑定、推送订阅、已读回执、账号管理 |
| M-06 收货核销 | 回收员端独立应用；ScanKit + 手工码、驿站校验、实际重量/成色、拒收原因、幂等校验 | 当前本机数据；无云端鉴权/事务和真实图片证据上传 |
| M-07 上架与处置 | 上架表单、货位冲突、报废表单、原因、一次性积分结算 | 缺建议积分人工确认/调整日志、报废照片上传和真实后台库存同步 |
| M-08 驿站运营 | 本驿站工作台指标、台账、库存、流转记录入口 | 体验数据按本机过滤；真实的后端行级隔离、公告、交接班/导出未接 |
| M-09 品类与因子管理 | 本地 JSON 因子目录含来源字段 | 原后台功能还在 Web；ArkTS 没有管理界面，缺版本/生效日期/变更日志 |
| M-10 内容与库存管理 | 审核仅在学生端暂无，待云端审核接口；回收端只做上架/报废 | 管理后台鸿蒙化未开始；缺筛选、强制下架、审计日志 |
| M-11 用户与权限管理 | 回收员体验入口允许选一个演示驿站 | 无真实账号、角色分配、禁用、服务端 RBAC、积分人工调整 |
| M-12 数据统计与报表 | 未实现鸿蒙管理统计 | Web 后台维持原实现；鸿蒙缺趋势图、分类/驿站对比、Excel 导出 |
| M-13 智能扩展 | 学生有本机规则查询入口 | AI 拍照识物、ASR 语音发布、自然语言云查询、可视化大屏未移植/联通 |
| F-15 积分规则与驿站管理 | 未移植为鸿蒙管理配置页 | 规则与驿站管理仍属于原 Web 管理后台；鸿蒙端缺少管理界面、版本追溯和变更日志 |

## 本次变更完成的部分

- 从一个页面内的三角色切换，调整为两个可分别安装的鸿蒙工程；学生端、回收员端使用不同应用包名与独立启动入口。
- 学生端恢复五区导航；增加发布、搜索/品类筛选、物品详情、预约单与码、取消、发布记录撤回、积分明细、资料/动态/帮助/排行榜/本地查询入口。
- 回收员端恢复独立体验入口；增加工作台、台账、待处置、扫码收货/领取、拒收、上架和报废表单。
- 两个工程分别通过 HarmonyOS 6.0.1（API 21）`assembleHap` 编译。

## 完整验收前的阻塞项

1. 配置可访问的 CICRS 测试环境（CloudBase 环境 ID、API/云函数调用方式、客户端鉴权方式、图片上传策略）。不应把服务密钥放入客户端。
2. 将状态机、预约容量与核销/积分结算改为云端事务；两个客户端仅消费服务端接口。本机仓储保留为开发 mock，不可用于生产积分。
3. 对照原学生 27 页与回收员独立小程序逐页补齐交互，再把 admin-web 的 Web 功能作为当前三端中的第三端保留或另立鸿蒙管理端范围。
4. 在 DevEco 模拟器/真机逐流程验收；本机 `hdc list targets` 当前返回空设备，尚不能声称已安装/运行验证。

## 运行

分别在 DevEco Studio 打开 `CICRS-Student-Harmony` 与 `CICRS-Recycler-Harmony`。两个工程的命令行构建方法见各自 README。当前 HAP 未签名，安装到设备前需要在 DevEco 配置调试签名。
